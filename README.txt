MIDNIGHT PAGES - UPDATED READING FEATURE

1. Keep index.html and script.js in the same folder.
2. Open index.html in a browser.
3. Log in or create a reader account, then open the Books page.
4. Select Read / Continue reading. Page progress saves automatically: page 1 of 10 = 10%, page 2 = 20%, and so on.

The six starter titles contain original 10-page reading guides and discussion prompts, not the full copyrighted books. Books added by users receive a 10-page original reading guide based on their description.

Progress is stored in this browser using localStorage. Clearing browser data will clear locally saved progress.
